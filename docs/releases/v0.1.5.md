The ESP32-C3 and C6 firmware now trades on real boards, and PokeUDS can ask an X / Y console for a trade (PokeUDS
hosting the trade), confirmed on hardware. Update from 0.1.4 with the green **Update** entry at the foot of the left
rail. This is the first update 0.1.4's updater makes: if it fails, download `PokeUDS-windows.zip` and unzip it over
your `PokeUDS` folder (your `Bank`, `Data` and `received` folders are not in the zip and stay as they are).

## New

- **ESP32-C3 and ESP32-C6:** confirmed on real boards with firmware 2.0-uds. X / Y with the 3DS asking traded on both;
  with PokeUDS asking, on the C6. The Board page installs the firmware on either, as on an S3.
- **X / Y with PokeUDS asking now trades** (it did not in 0.1.4). Four fixes, each read off the game itself:
  - the request names a trade the way a retail console's does (byte 0x96 = 01; PokeUDS sent 02);
  - once it has asked, PokeUDS stays on the console's channel while the player reads the request and accepts (it
    hopped channels after 8 s; a player took 20 s in one capture);
  - only a real answer counts: a console's idle beacon that still named PokeUDS from an earlier trade read as one;
  - the trade network PokeUDS hosts carries its request, as the game's does, so the console knows it is PokeUDS's
    and joins it.
- **Boards:** a board checked or installed on the Board page is the one the Trade page uses, so a new board's port
  replaces an old board's. The Trade page's Check always ends with an answer: a port with no board on it says which
  ports have one, and a board that stops answering is given up on.
- **Logs:** every log box has **Copy log** (the whole run, every line) and **Open logs folder**, and says which file
  the run is saved in. The file is written as the run goes, so a run that is still going, or that ended when the app
  was closed, keeps its log; before, only runs that ended by themselves were saved, and long ones lost their start.

## Pre-alpha

- **DS Wi-Fi Mystery Gifts (Gen 4 / 5):** a stand-in for Nintendo WFC for Diamond, Pearl, Platinum, HeartGold,
  SoulSilver, Black, White, Black 2 and White 2: DNS, the connection test, the NAS login and the gift download over the
  DS's SSL 3.0, with a certificate made from your own Wii certificate, serving PKHeX's official cards. From the
  command line only (`python -m pokeuds wfc`), from source, with `pip install -r requirements-wfc.txt`. **Not yet
  tried on a DS.** See `docs/ds_wifi.md`.

## Not tested yet

- PokeUDS asking (hosting) in Gen 1 / 2 (Virtual Console) and in Sun / Moon and Ultra Sun / Ultra Moon.
- PokeUDS asking with Omega Ruby / Alpha Sapphire, and on the S3 and C3.
- The classic ESP32.
- The GTS over the public relays between two different computers.
- Japanese, Korean and non-English international Virtual Console titles on a console.

## Known issues

- An alpha: expect rough edges, and keep backups of anything you trade away.
- Started from a sandboxed shell (a terminal inside some tools), the app runs with restricted rights and cannot write
  its files: start it from Explorer.
