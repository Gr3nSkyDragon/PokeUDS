A fixes release: Flet 1.1.2 (the toolkit pokeldn uses), file dialogs that open on the Mac, a download speed on the
update banner, and clearer errors when installing firmware fails. Update from 0.2.0 with the green **Update** entry at
the foot of the left rail; if it fails, download `PokeUDS-windows.zip` and unzip it over your `PokeUDS` folder (your
`Bank`, `Data` and `received` folders are not in the zip and stay as they are).

## Fixed

- **Mac, file dialogs:** opening or saving a file (gift cards, Pokemon files, exports) failed with
  `ENTITLEMENT_NOT_FOUND`. Flet's window is now signed with the permission its file dialogs need, as pokeldn does, and
  the build stops if it is missing.
- **Mac, installing firmware:** esptool and its serial and reset code are bundled whole, so the app no longer depends
  on the build guessing which of their modules it needs. If installing still fails in an unexpected way, the Board
  page's log (and `pokeuds board flash`) shows where the error came from: please include it in a report.
- **Board page:** the firmware texts no longer talk about a Switch side restarting into its 3DS mode. PokeUDS's
  firmware has no Switch side.

## Changed

- **Updates:** the download shows its speed ("12 of 80 MB (2.4 MB/s)"), averaged over the last few seconds.
- **Flet 1.1.2:** the window, dialogs and menus keep their tinted look. On weak graphics cards the window draws with
  Skia, as before (`FLET_NO_IMPELLER=false` turns Flet's newer renderer back on).
- **Saving files:** Flet 1.1's save dialog creates the chosen file before PokeUDS writes it. When PokeUDS adds the
  extension, it removes the empty file, so no stray one is left beside it.

## Not tested yet

- File dialogs and installing firmware in the Mac app, on a Mac (the build checks the window's permission and that
  esptool reaches the port).
- Still from 0.1.8: firmware 2.1-uds on a board; PokeUDS on a Mac with a board on the ldn line; Gen 5 gifts and the
  builder's Gen 4 Pokemon and Gen 5 cards sent by PokeUDS itself; PokeUDS hosting the Time Capsule; Omega Ruby /
  Alpha Sapphire and Ultra Sun / Ultra Moon on a console; the classic ESP32; online trades and Touch Trade between two
  real 3DSs.
- Sending a Gen 4 key item (the Secret Key, Member Card, Oak's Letter) or a Pokéwalker course to a DS.
- The Mac app's single Dock icon, on a Mac (the build checks the setting is there).

## Known issues

- An alpha: expect rough edges, and keep backups of anything you trade away.
- After an X / Y trade, choosing to register PokeUDS's trainer as a friend fails on the 3DS: PokeUDS has no friend
  data to give it.
- Flashing any firmware erases the keys a board stores. PokeUDS doesn't use them, but Azahar and uds-esp32-setup users
  have to store theirs again.
- A custom card's Pokemon matches no real event, so PKHeX flags it ("Unable to match to a Mystery Gift").
- In a very narrow window the Gifts page's filter boxes narrow until their labels are cut short.
- The packaged app keeps its bank (and GTS listings) in the `Bank` folder beside it; running from source keeps them
  in your user profile. Listings made in one do not show in the other.
- The Windows app is unsigned: Windows may warn about an unknown publisher on first start (More info, Run anyway).
- Started from a sandboxed shell (a terminal inside some tools), the app runs with restricted rights and cannot write
  its files: start it from Explorer.
