PokeUDS can now host the Virtual Console trades: with **PokeUDS hosts** chosen, a retail 3DS joins it from the VC
link menu, confirmed on hardware in Gen 1 (Red / Blue / Yellow) and Gen 2 (Gold / Silver / Crystal). X / Y now trades
in both directions, and a Gen 6 Mystery Gift sent over local wireless reached a retail X. Update from 0.1.5 with the
green **Update** entry at the foot of the left rail; if it fails, download `PokeUDS-windows.zip` and unzip it over your
`PokeUDS` folder (your `Bank`, `Data` and `received` folders are not in the zip and stay as they are).

## New

- **Virtual Console hosting works** (it did not in 0.1.5: no console joined). PokeUDS's network now matches a retail
  VC host's, read off scans of retail hosts, a sniff of two retail consoles and Azahar hosting a retail joiner:
  - network id 1 and attributes 0x8000, with application data shaped like a retail host's;
  - Blue and Silver host on Red's and Gold's comm ids, as the retail games do;
  - every frame broadcast on the air, and the joiner's setup answered message by message;
  - the host's system data sent again until the console acknowledges it, and only then its Start (the first unit,
    `EF`, flagged as a retail host flags it), which takes the console from the link menu to the Cable Club.
  The Trade page, the command line and the docs no longer call VC hosting experimental.
- **ESP32-C3 and C6:** the Board page no longer marks their firmware alpha.
- **The GTS** has traded over the public relays.
- A banner above every page points players looking for the Switch games to
  [PokeLDN](https://github.com/Decryptu/pokeldn); its close button hides it for good.
- The log of a VC trade shows the setup traffic, the first units each way and per-channel counts, and `python -m
  pokeuds scan` prints each network's attributes, for reports from hardware.
- Docs: the command line has its own page (`docs/cli.md`), the code layout moved to `docs/architecture.md`, and the
  README credits every project PokeUDS builds on. The Windows app is not code-signed: the release workflow is
  prepared for SignPath Foundation's signing, which PokeUDS is working towards (`docs/code_signing.md`).

## Pre-alpha

- **DS Wi-Fi Mystery Gifts (Gen 4 / 5):** unchanged from 0.1.5; from the command line only, **not yet tried on a DS**
  (`docs/ds_wifi.md`).

## Not tested yet

- PokeUDS hosting the Time Capsule (a Gen 1 Pokemon offered to Gold / Silver / Crystal with PokeUDS hosting).
- Omega Ruby / Alpha Sapphire and Ultra Sun / Ultra Moon on a console (they use X / Y's and Sun / Moon's values).
- The classic ESP32.
- Japanese, Korean and non-English international Virtual Console titles on a console.

## Known issues

- An alpha: expect rough edges, and keep backups of anything you trade away.
- The Windows app is unsigned: Windows may warn about an unknown publisher on first start (More info, Run anyway).
- Started from a sandboxed shell (a terminal inside some tools), the app runs with restricted rights and cannot write
  its files: start it from Explorer.
