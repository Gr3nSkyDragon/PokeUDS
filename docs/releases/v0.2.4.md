PokeUDS.exe can now be moved out of its folder without breaking the app, and PokeUDS offers a desktop shortcut. Update
from 0.2.3 with the green **Update** entry at the foot of the left rail; if it fails, download `PokeUDS-windows.zip`
and unzip it over your `PokeUDS` folder (your `Bank`, `Data` and `received` folders are not in the zip and stay as
they are).

## New

- **The launcher (Windows):** `PokeUDS.exe` is now a small launcher, and the app itself is
  `_internal\PokeUDS-app.exe`. Before, dragging `PokeUDS.exe` to the Desktop left it unable to start. Now a moved
  `PokeUDS.exe` still opens PokeUDS: it goes back to the folder PokeUDS last ran from, or looks for it next to itself
  and in Desktop, Downloads and Documents. If it finds none (or several), it asks: point it at the `_internal` folder
  that came in the download, once, and it remembers. Your `Bank`, `Data` and `received` stay in the PokeUDS folder,
  wherever the launcher is.
- **Desktop shortcut (Windows):** a bar above the pages offers **Create desktop shortcut**. It shows until you use it
  or close it; **Settings, Desktop shortcut** has the same button afterwards. A shortcut is the best way to start
  PokeUDS from the Desktop: `PokeUDS.exe` stays in its folder.

## Changed

- **Updating:** the folder keeps `PokeUDS.exe` and `_internal` at the top, as before, so 0.2.3 and older update to the
  new layout the usual way. Only `PokeUDS.exe`, `_internal` and `LICENSE.txt` are replaced.
- **One file outside the folder:** PokeUDS now writes one line to `%LOCALAPPDATA%\PokeUDS\home.txt`, the folder it last
  started from, so a moved `PokeUDS.exe` can find it. Everything else stays in the PokeUDS folder.
- **Building from source (Windows):** `build_exe.cmd` now also needs Microsoft's C compiler (Visual Studio or its
  Build Tools, "Desktop development with C++") to build the launcher.
- The Mac app is unchanged: a `.app` already moves as one piece.

## Tested

- The launcher on the built app: started in its folder and after being moved, the search, both "which folder" dialogs
  and the folder picker, the command line (`PokeUDS.exe --cli ...`), the desktop shortcut, and an update into the new
  layout from 0.1.6 and from a launcher build, with the player's files left as they were.
- The machine translations in the running app, in several languages besides Japanese.

## Known issues

- An alpha: expect rough edges, and keep backups of anything you trade away.
- The translations are machine-made: some wording may be off.
- A copy of PokeUDS's folder is a second player with its own bank; a moved `PokeUDS.exe` opens the one that started
  last.
- An S2 cannot be reset into download mode by PokeUDS: use its BOOT and RESET buttons for every install.
- After an X / Y trade, choosing to register PokeUDS's trainer as a friend fails on the 3DS: PokeUDS has no friend
  data to give it.
- Flashing any firmware erases the keys a board stores. PokeUDS doesn't use them, but Azahar and uds-esp32-setup users
  have to store theirs again.
- A custom card's Pokemon matches no real event, so PKHeX flags it ("Unable to match to a Mystery Gift").
- In a very narrow window the Gifts page's filter boxes narrow until their labels are cut short.
- The packaged app keeps its bank (and GTS listings) in the `Bank` folder beside it; running from source keeps them
  in your user profile. Listings made in one do not show in the other.
- The Windows app is unsigned: Windows may warn about an unknown publisher on first start (More info, Run anyway).
- Started from a sandboxed shell (a terminal inside some tools), the app runs with restricted rights and cannot write
  its files: start it from Explorer.
